# Loopy

Minimalist, distraction-free YouTube video and lo-fi looper.

**Live site:** https://loopy-music.vercel.app

![Loopy screenshot](screenshot.png)

## Features

- Infinite single video looping
- Playlist looping
- Audio-only performance mode
- Playlists and settings kept locally

## Tech Stack

- [Vite](https://vite.dev/)
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/)
- [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)
- Hosted on [Vercel](https://vercel.com)
